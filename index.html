GitHub Game Index Builder

Static page, runs fully in your browser. It loads your GitHub repos with an access token, auto-ticks the ones that look like games, and builds a plain website with a link to every one of them (play link if GitHub Pages / homepage exists, otherwise the repo page). Download the site as index.html or publish it straight to a GitHub Pages repo.

1. Token

Classic token with repo scope = listing + publishing. Read-only token = listing + download only. The token is only sent to api.github.com from this page.

2. Repos – untick anything that is not a game
Not loaded yet.
3. Build / download / publish the site





Publish creates the repo if it does not exist, commits index.html, enables Pages, and gives you the URL. If a repo with that name already exists, its index.html gets overwritten. First Pages build takes about a minute. Repo list = your own (owner) repos only.
